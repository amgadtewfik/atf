| --- | --- | --- | --- |

## Installation

1. Download `ATF Chat-arm64.dmg`.
2. Open the DMG file.
3. Drag **ATF Chat** to the Applications folder.
4. Launch ATF Chat from Applications.

## Requirements

- macOS on an Apple Silicon Mac.
